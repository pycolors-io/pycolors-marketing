# Plus Jakarta Sans wordmark font

Unmodified Latin WOFF2 served by Google Fonts for the existing 700/800
wordmark weights. Both requested weights resolve to the same variable font
(200–800); the application keeps using 700/800.

- Version: 2.071.
- Source: [Google Fonts WOFF2](https://fonts.gstatic.com/s/plusjakartasans/v12/LDIoaomQNQcsA88c7O9yZ4KMCoOg4Ko20yygg_vb.woff2).
- Upstream: [Plus Jakarta Sans](https://github.com/tokotype/PlusJakartaSans).
- License: SIL Open Font License 1.1; see [OFL.txt](./OFL.txt).
- Retrieved: 2026-10-02.
- SHA-256: `cd8db90cd950e26bc8761f65d323588bd5cd112d326d6d322bc7c8ea86771215`.

This local asset avoids a Next.js 16.1.1 Turbopack failure when Google serves
font URLs containing query parameters. Keep the license with the font.
