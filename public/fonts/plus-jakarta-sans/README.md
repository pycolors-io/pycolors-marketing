# Plus Jakarta Sans local font

Unmodified Latin WOFF2 variable font (200–800), used by Theme Builder and
Starter Pro. The shared appearance stylesheet registers the local font for
previews and application typography.

- Version: 2.071.
- Source: [Google Fonts WOFF2](https://fonts.gstatic.com/s/plusjakartasans/v12/LDIoaomQNQcsA88c7O9yZ4KMCoOg4Ko20yygg_vb.woff2).
- Upstream: [Plus Jakarta Sans](https://github.com/tokotype/PlusJakartaSans).
- License: SIL Open Font License 1.1; see [OFL.txt](./OFL.txt).
- Retrieved: 2026-10-02.
- SHA-256: `cd8db90cd950e26bc8761f65d323588bd5cd112d326d6d322bc7c8ea86771215`.

The local asset keeps previews and standalone applications independent of
runtime requests to Google Fonts. Keep the license with the font.
