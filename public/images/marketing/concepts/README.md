# Marketing decorative illustrations

These images are decorative visual metaphors:

- `product-launch-v1.webp`: a product launch.
- `modular-platform-v1.webp`: a modular product foundation.

They are not application or customer screenshots, physical products, or proof
of an integration. Keep genuine interface previews separately captioned. Use
empty alt text inside an `aria-hidden` presentation container, reserve image
space, and load below-the-fold images lazily with responsive sizes.
