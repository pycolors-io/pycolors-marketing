# Marketing concept illustrations

Two original decorative renders created with the built-in imagegen tool for
PyColors marketing cards. Exact prompts, dimensions and hashes are recorded in
[prompts-v1.json](prompts-v1.json).

- product-launch-v1.webp: a curved ivory sheet, coral panel and yellow plinth
  representing a product launch.
- modular-platform-v1.webp: interlocking cobalt and silver architectural forms
  representing a modular product foundation.

These are visual metaphors, not application screenshots, physical products or
proof of an integration. Use empty alt text inside an aria-hidden presentation
container. Keep genuine interface previews separately captioned. No Apple,
Revolut or Stripe assets, logos or devices are included.

The originals remain in the imagegen output folder; these project copies use
WebP compression without changes to composition or aspect ratio. Reserve image
space and use Next Image with responsive sizes and lazy loading below the fold.
