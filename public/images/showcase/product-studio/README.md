# Product studio reference captures

PyColors-owned reference implementation of the existing Starter Pro demo. All
people, projects, activity and discussions are fictional fixtures. This is not a
customer product, testimonial or evidence of commercial results.

The images show the workspace overview and Launch checklist in light and dark
appearances:

- `dashboard-coral-light.png` / `dashboard-coral-dark.png`: workspace overview.
- `project-coral-light.png` / `project-coral-dark.png`: project tasks and discussion.

These are genuine interface captures with synthetic data, rather than decorative
illustrations. They do not demonstrate a live third-party integration, payment,
or email delivery. Demonstration dates and counts may vary.
