# Starter Pro decorative illustration experiments

Six original illustrations generated on 2026-11-12 with the built-in imagegen
tool for a local marketing-design experiment.

| Asset                             | Visual metaphor                          |
| --------------------------------- | ---------------------------------------- |
| `source-stack-test-v1.png`        | Modular source foundations               |
| `delivery-case-test-v1.png`       | A downloadable source package            |
| `billing-loops-test-v1.png`       | Recurring connections and reconciliation |
| `workflow-path-test-v1.png`       | Connected product workflows              |
| `recovery-loop-test-v1.png`       | An operations recovery path              |
| `connected-workspace-test-v1.png` | Connected workspaces                     |

The RGBA PNGs have transparent backgrounds. Their exact dimensions, file sizes
and generation prompts are recorded in [prompts-v2.json](prompts-v2.json).
[prompts-v1.json](prompts-v1.json) retains the first two-image experiment.
The page loads the artwork lazily through Next Image at its standard quality of
75, reserving the image areas before the files load.

These are decorative spatial renders, not application screenshots, physical
products, interface designs or evidence of an integration. Their containers are
hidden from assistive technology and the images have empty alt text; the card
headings, existing feature lists and setup instructions convey the information.

The genuine interface captures and their demonstration-data disclosures remain
unchanged. No Apple image, device, logo or artwork is included. The Apple Store
and iPad pages supplied by the owner informed the spacious presentation direction.

The same six assets are reused across the six readiness cards, the six foundation
gallery cards, four post-purchase cards and the configuration panel. The recurring
work gallery uses only decorative spatial illustrations. Genuine application
captures remain in the separate hero and product-preview sections, with their
accessible descriptions and demonstration-data disclosures.
