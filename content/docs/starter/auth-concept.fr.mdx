## Vue d’ensemble [#overview]

L'authentification est la **point d'entrée de chaque produit SaaS**.

Starter Free vous donne un complet **surface d'authentification**:

- connexion
- enregistrer
- mot de passe oublié
- validation
- états de chargement
- États d'erreur
- rediriger les flux

Mais **Aucun fournisseur n'est câblé**.

C'est intentionnel.

<Callout title="Idée de base">
  Starter Free définit les **auth UX contract**. Vous branchez le fournisseur
  lorsque votre produit devient réel.

</Callout>

## Modèle mental [#mental-model]

> L'interface utilisateur est stable. La mise en œuvre est remplaçable.

| Couche              | Responsabilité                           |
| ------------------- | ---------------------------------------- |
| UI                  | Formulaires, états, validation, feedback |
| Routage             | Redirections, pages protégées            |
| Fournisseur         | Sessions, tokens, identité               |
| Backend (plus tard) | autorisations, rôles, contrôle d'accès   |

## Câblage de votre fournisseur [#wiring-your-provider]

Starter Free est indépendant du fournisseur :

- Auth.js / NextAuth
- Greffier
- Supabase Auth
- Backend personnalisé

```tsx title="auth-action.ts"
async function onSubmit(values) {
  await signIn(values.email, values.password);
  router.push("/dashboard");
}
```
