## Construire une véritable surface SaaS en quelques minutes [#build-a-real-saas-surface-in-minutes]

Starter Free est un **Prochaine.js surface SaaS** conçu pour vous aider à valider une idée de produit plus rapidement.

Ce n'est pas un dépôt blanc. Ce n'est pas une démo de jouets. Ce n'est pas un boilerplate lourd.

Il vous donne une interface produit crédible que vous pouvez:

- Exécutez localement en quelques minutes
- Explorez comme une vraie application
- s'adapter à votre propre domaine
- Présenter aux utilisateurs, clients ou investisseurs

</Callout>

## Ce que c'est [#what-it-is]

Starter Free est :

- Une première fondation SaaS
- une surface d'interface utilisateur adaptées à la production
- une véritable structure de produit
- un outil de validation pour votre idée
- un moyen rapide de créer une démo SaaS crédible

Starter Free n'est pas :

- un backend SaaS complet
- un système d'auth entièrement câblé
- un vrai moteur de facturation Stripe
- un produit soutenu par une base de données
- un faux terrain de jeu

<Callout type="info" title="Frontend-first par design">
  Starter Free conserve l'authentification, la facturation et les données
  simulées afin que vous puissiez valider le produit avant de vous engager dans
  la complexité du backend.

</Callout>

## Pour qui c'est ? [#who-it-is-for]

Utilisez Starter Free si vous êtes :

- Construire un MVP SaaS
- Valider une idée de produit
- Créer une démo pour les utilisateurs ou les investisseurs
- Concevoir un produit avant les décisions du backend
- Expédition rapide avec une approche frontend-first

Il est particulièrement utile lorsque vous avez besoin d'une surface de produit crédible avant que l'infrastructure de production en vale le coût.

## Moment de mise à niveau [#upgrade-moment]

Starter Free vous aide à démarrer rapidement.

Passez à Starter Pro lorsque votre produit a besoin :

- Authentification réelle
- Stripe Checkout
- Routes protégées
- API backend
- Accès basé sur les rôles
- données de production

## Pourquoi cela compte [#why-this-matters]

La plupart des projets ralentissent avant que les utilisateurs ne voient le produit parce que:

- UX est construit trop tard
- La complexité du backend commence trop tôt
- la surface du produit n'est pas assez visible
- facturation et auth deviennent des bloqueurs avant validation

Starter Free corrige cela en vous donnant quelque chose de réel tôt.
