## Actions compactes dans le contexte [#compact-actions-in-context]

Les **Menu déroulant** Composant affiche une liste d'actions à l'intérieur d'une surface flottante ancrée à un déclencheur.

Utilisez-le pour:

- actions en ligne
- Menus de compte
- menus de l'éditeur
- listes de commandes compactes
- Actions secondaires
- sélecteurs d'options
- petits choix contextuels

Le menu déroulant est construit sur **Radix DropdownMenu** et stylisé avec des tokens PyColors tels que `bg-popover`, `border-border`et `text-popover-foreground`.

<Callout title="Idée de base">
  Le menu déroulant est pour les actions contextuelles compactes. Il ne devrait
  pas devenir une surface de flux de travail complète.

</Callout>

### Importation [#import]

```tsx title="dropdown-menu-import.tsx"
import { DropdownMenu } from "@pycolors/ui";
```

Utilisation `DropdownMenuTrigger asChild` avec un déclencheur sémantique, généralement un bouton.

### Utilisations [#usage-patterns]

<Steps>
  <Step>
    #### Commencez par le déclencheur [#start-with-the-trigger]

    Utilisez un déclencheur clair tel que `Actions`, `More`ou un bouton d'icône avec une étiquette accessible.

</Step>

  <Step>
    #### Gardez les éléments orientés vers l'action [#keep-items-action-oriented]

    Préférez les étiquettes verbe-first : Renommer, Dupliquer, Archiver, Exporter, Supprimer.

</Step>

  <Step>
    #### Groupe seulement si nécessaire [#group-only-when-needed]

    Utilisez des étiquettes et des séparateurs pour clarifier la structure, pas pour décorer le menu.

</Step>

  <Step>
    #### Confirmer les actions destructrices [#confirm-destructive-actions]

    Un élément de menu destructeur devrait généralement ouvrir une boîte de dialogue avant l'action finale.

</Step>

  <Step>
    #### Déplacer des workflows complexes ailleurs [#move-complex-workflows-elsewhere]

    Si le menu contient des formulaires, du contenu long ou des décisions en plusieurs étapes, utilisez Sheet, Boîte de dialogue ou une page.

</Step>

</Steps>

## Menu déroulant vs Dialog vs Sheet [#dropdown-menu-vs-dialog-vs-sheet]

| Situation                            | Utilisation    |
| ------------------------------------ | -------------- |
| Actions en ligne                     | menu déroulant |
| Menu Compte                          | menu déroulant |
| Petit sélecteur de préférences       | menu déroulant |
| Confirmation destructive             | boîte dialogue |
| Filtres avancés                      | Sheet          |
| Flux de travail des paramètres longs | Sheet ou page  |
| Débit en plusieurs étapes            | Page           |

<Callout type="info" title="Règle de décision">
  DropdownMenu expose les choix compacts. Le dialogue confirme les décisions
  ciblées. Sheet gère des flux de travail latéraux plus importants.

</Callout>

## API [#api]

#### Composante [#component]

| Composante                 | Désignation                                    |
| -------------------------- | ---------------------------------------------- |
| `DropdownMenu`             | Récipient racine                               |
| `DropdownMenuTrigger`      | Élément d'ancrage, généralement avec `asChild` |
| `DropdownMenuContent`      | Surface de menu flottante                      |
| `DropdownMenuItem`         | Mesure standard                                |
| `DropdownMenuCheckboxItem` | Élément à bascule indépendant                  |
| `DropdownMenuRadioGroup`   | Groupe de sélection exclusif                   |
| `DropdownMenuRadioItem`    | Élément dans un groupe de radio                |
| `DropdownMenuLabel`        | Étiquette de section                           |
| `DropdownMenuSeparator`    | Diviseur                                       |
| `DropdownMenuShortcut`     | Raccourci visuel aligné à droite               |
| `DropdownMenuGroup`        | Emballage de groupe                            |
| `DropdownMenuSub`          | Sous-menu racine                               |
| `DropdownMenuSubTrigger`   | Élément déclencheur du sous-menu               |
| `DropdownMenuSubContent`   | Sous-menu                                      |
| `DropdownMenuPortal`       | Portal wrapper pour le contenu du menu         |

#### Ajouts d'emballage [#wrapper-additions]

| Composante               | Ajout de prop     | Objet                                                     |
| ------------------------ | ----------------- | --------------------------------------------------------- |
| `DropdownMenuItem`       | `inset?: boolean` | Aligner l'élément avec l'espacement des indicateurs       |
| `DropdownMenuLabel`      | `inset?: boolean` | Aligner l'étiquette sur les éléments insérés              |
| `DropdownMenuSubTrigger` | `inset?: boolean` | Aligner le trigger du sous-menu avec les éléments insérés |

Les composants du menu déroulant étendent leurs accessoires Radix respectifs.

```ts title="dropdown-menu-props.ts"
React.ComponentPropsWithoutRef<typeof DropdownMenuPrimitive.Root>;
React.ComponentPropsWithoutRef<typeof DropdownMenuPrimitive.Trigger>;
React.ComponentPropsWithoutRef<typeof DropdownMenuPrimitive.Content>;
React.ComponentPropsWithoutRef<typeof DropdownMenuPrimitive.Item>;
```

### Accessibilité [#accessibility]

Le menu déroulant est construit sur les primitives Radix DropdownMenu.

La prise en charge du clavier comprend :

- Entrer ou Espace active un élément
- Touches fléchées pour naviguer
- Escape ferme le menu
- Sous-menus support clavier navigation
- Le focus revient au déclencheur lorsqu'il est fermé

Directives :

- utilisation `DropdownMenuTrigger asChild` avec un déclencheur sémantique
- fournir un `aria-label` pour les déclencheurs icon-only
- éviter les entrées complexes dans les menus déroulants
- Ne comptez pas sur le texte de raccourci comme seule instruction
- confirmer les actions destructrices dans une boîte de dialogue si nécessaire

<Callout title="Règle d'accessibilité">
  Un menu déroulant devrait être rapide à numériser et rapide à quitter. Si les
  utilisateurs doivent penser, lire ou taper, utilisez une autre surface.

</Callout>

## Questions courantes [#common-questions]

<Accordions type="single">
  <Accordion title="Un menu déroulant peut-il contenir un formulaire ?">
    Habituellement non. Utilisez Sheet, Dialog ou une page dédiée pour les formulaires. Les menus déroulants sont les meilleurs pour les actions courtes et les choix compacts.
  </Accordion>

<Accordion title="Les actions destructrices devraient-elles vivre dans le menu déroulant?">
  Le menu peut exposer l'action destructrice, mais la confirmation finale
  devrait généralement se produire dans une boîte de dialogue.
</Accordion>

<Accordion title="Quand dois-je utiliser la case à cocher ou les éléments de menu radio?">
  Utilisez des cases à cocher pour les bascules indépendantes. Utilisez des
  éléments radio quand exactement une option doit être sélectionnée.
</Accordion>

  <Accordion title="Les raccourcis sont-ils automatiques ?">
    Non. `DropdownMenuShortcut` Il est uniquement visuel. L'enregistrement du raccourci clavier doit être mis en œuvre séparément.
  </Accordion>
</Accordions>
