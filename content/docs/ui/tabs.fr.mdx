## Basculer entre les vues associées [#switch-between-related-views]

Les **Onglets** Le composant permet aux utilisateurs de basculer entre les vues associées sans quitter la page.

Utilisez-le pour:

- sections de paramètres
- Vues tableau de bord
- sections de facturation
- panneaux de produits
- filtres compacts
- contenu segmenté
- Vues d'administration associées

Les onglets sont construits sur **Onglets Radix** et stylisé avec des tokens PyColors pour un thème cohérent, des états de focus et un comportement d'interaction.

<Callout title="Idée de base">
  Les onglets sont pour les vues par les pairs au même niveau hiérarchique. Ils
  ne doivent pas remplacer la navigation primaire.

</Callout>

### Tailles disponibles [#available-sizes]

| Taille | Objet                                                   |
| ------ | ------------------------------------------------------- |
| `sm`   | Interfaces utilisateur denses, filtres, barres d'outils |
| `md`   | Densité par défaut                                      |
| `lg`   | Espacement confortable, onboarding, surfaces marketing  |

<Callout type="info" title="Règle de densité">
  Utilisation `sm` pour les commandes de produits compacts, `md` pour la plupart
  des UI de produit, et `lg` uniquement lorsque les onglets ont besoin d'une
  présence visuelle plus forte.

</Callout>

## Tabs vs navigation vs filtres [#tabs-vs-navigation-vs-filters]

| Situation                                                       | Utilisation               |
| --------------------------------------------------------------- | ------------------------- |
| Basculer entre les vues des pairs                               | Onglets                   |
| Déplacer entre les pages ou les principaux domaines de produits | Navigation                |
| Basculer un petit filtre d'état                                 | Tabs ou contrôle segmenté |
| Sélectionner une valeur dans un formulaire                      | Groupe de radio           |
| Masquer ou révéler du contenu facultatif                        | Accordéon                 |
| Basculer entre des flux de travail non liés                     | Navigation des pages      |

<Callout title="Règle de décision">
  Si chaque option est une vue associée dans la même page, utilisez les onglets.
  Si chaque option est une destination, utilisez la navigation.

</Callout>

#### Composante [#component]

| Composante    | Désignation                                      |
| ------------- | ------------------------------------------------ |
| `Tabs`        | Récipient racine                                 |
| `TabsList`    | Trigger list, soutiens `size`                    |
| `TabsTrigger` | Déclencheur à onglet individuel, supports `size` |

| `TabsTrigger` | Étend Radix `TabsPrimitive.TabsTriggerProps` + `{ size?: TabsSize }` |
| `TabsContent` | Étend Radix `TabsPrimitive.TabsContentProps`                         |

### Accessibilité [#accessibility]

Les onglets sont construits sur les primitives Radix Tabs.

Directives :

- fournir un `aria-label` le `TabsList` ou l'associer à un titre visible
- Garder chaque `TabsTrigger` claire et textuelle lorsque cela est possible
- éviter que l'onglet icon-only se déclenche à moins qu'ils n'aient des étiquettes accessibles
- Gardez la navigation du clavier prévisible
- s'assurer que le contenu des onglets est significatif lorsqu'il est atteint directement
- éviter de cacher les actions critiques du produit derrière des onglets inactifs

Radix fournit le support du clavier:

- Les touches fléchées se déplacent entre les déclencheurs
- Enter ou Space active un déclencheur en fonction du mode d'activation
- focus management suit la sémantique des tablists

<Callout title="Règle d'accessibilité">
  Une étiquette de tabulation doit décrire clairement le contenu qu'elle révèle.

</Callout>

## Questions courantes [#common-questions]

<Accordions type="single">
  <Accordion title="Les onglets doivent-ils mettre à jour l'URL ?">
    Parfois. Si les utilisateurs ont besoin de partager ou de recharger un onglet spécifique, synchronisez l'état de l'onglet sur la page ou la couche de routage.
  </Accordion>

<Accordion title="Combien d'onglets sont trop nombreux?">
  Plus de cinq devient généralement difficile à scanner. Envisagez plutôt la
  navigation, une barre latérale ou une disposition de paramètres.
</Accordion>

<Accordion title="Les onglets peuvent-ils contenir des formulaires ?">
  Oui. Les onglets sont communs dans les pages de paramètres. Conservez la
  portée de la soumission et de la validation du formulaire clairement pour
  chaque panneau.
</Accordion>

  <Accordion title="Les onglets doivent-ils être utilisés pour les filtres ?">
    Les onglets peuvent fonctionner pour un petit ensemble de filtres stables. Pour les filtres complexes, utilisez une barre d'outils ou un panneau latéral.
  </Accordion>
</Accordions>
