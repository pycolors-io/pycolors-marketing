## Vue d’ensemble [#overview]

Le rayon d'angle est l'un des signaux visuels les plus forts d'un système d'interface utilisateur.

Il influence directement la façon dont votre produit se sent:

- tranchant ou doux
- dense ou respirant
- utilitaire ou premium
- rigide ou amical

PyColors définit un **petite échelle de rayon contrôlée** Ainsi, chaque surface semble cohérente à travers:

- composants
- tableaux de bord
- formulaires
- documentation
- pages marketing

<Callout title="Pourquoi cela compte">
  Le rayon incohérent est l’un des moyens les plus rapides de briser la
  cohérence visuelle. Même de petites différences créent un sentiment subtil de
  «quelque chose ne va pas».

</Callout>

## Étapes [#steps]

<Steps>

<Step>
### Définir un rayon de base [#define-a-base-radius]

Commencez à partir d'une seule variable.

```css title="tokens.css"
:root {
  --radius: 0.625rem;
}
```

Ensuite, vous en tirerez toute l’ampleur.

```css title="tokens.css"
@theme inline {
  --radius-sm: calc(var(--radius) - 4px);
  --radius-md: calc(var(--radius) - 2px);
  --radius-lg: var(--radius);
  --radius-xl: calc(var(--radius) + 4px);
}
```

Cela vous permet d'ajuster l'ensemble du produit à partir d'un seul endroit.

</Step>

<Step>
### La carte des rayons à Tailwind [#map-radius-to-tailwind]

Exposez les tokens via Tailwind pour que les composants restent cohérents.

```ts title="tailwind.config.ts"
borderRadius: {
  sm: "var(--radius-sm)",
  DEFAULT: "var(--radius-md)",
  md: "var(--radius-md)",
  lg: "var(--radius-lg)",
  xl: "var(--radius-xl)",
}
```

À partir de là, les composants n'utilisent que des utilitaires sémantiques.

</Step>

## Échelle de rayon [#radius-scale]

| Token         | Utilisation                                    |
| ------------- | ---------------------------------------------- |
| `--radius-sm` | interface utilisateur dense, éléments compacts |
| `--radius-md` | contrôles par défaut                           |
| `--radius-lg` | cartes et surfaces                             |
| `--radius-xl` | modaux et conteneurs exceptionnels             |

## Guide de décision [#decision-guide]

Utilisez ce système si :

- vous voulez une cohérence visuelle à travers de nombreux composants
- vous créez des tableaux de bord ou des produits SaaS
- vous voulez des thèmes prévisibles
- vous voulez que les composants restent réutilisables

Évitez les remplacements locaux si :

- la valeur est utilisée à plusieurs endroits
- il casse la cohérence avec les composants existants
- il introduit le bruit visuel
- il n'appartient pas à un modèle réutilisable

## Pourquoi c'est important [#why-it-matters]

Le rayon est subtil, mais il façonne la perception instantanément.

- rayon constant au produit se sent intentionnel
- rayon incohérent au produit se sent non poli

Garder le rayon contrôlé garantit que votre interface utilisateur reste:

- prévisible
- évolutif
- visuellement calme
