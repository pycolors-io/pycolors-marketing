      <Tab value="Install UI">

```bash title="Terminal"
pnpm add @pycolors/ui @pycolors/tokens
```

In a React app with Tailwind CSS v4, [connect the styles next](/docs/ui/installation#add-design-tokens).

      </Tab>
      <Tab value="Run Starter Free">

```bash title="Terminal"
git clone https://github.com/pycolors-io/pycolors-starter-free.git
cd pycolors-starter-free
pnpm install
pnpm dev
```

Explore the frontend with its demo data. [Follow the setup guide](/docs/starter/installation).

      </Tab>
      <Tab value="Set up Pro">

```bash title="Terminal"
cp .env.example .env
pnpm install --frozen-lockfile
```

After downloading and unzipping your purchase, run these commands in its folder. [Continue setup](/docs/starter-pro/getting-started#setup-flow).
