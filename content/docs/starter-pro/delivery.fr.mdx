Vous pouvez télécharger le code source acheté chez PyColors et récupérer votre accès sans créer de compte. Pour configurer les abonnements de votre propre application, consultez le [guide de facturation](/docs/starter-pro/billing).

<Callout title="Vous avez payé et le téléchargement reste inaccessible ?">
  Vérifiez la boîte de réception et les courriers indésirables de l’adresse
  utilisée lors du paiement. Si celui-ci est confirmé, [demandez un nouveau lien
  d’accès](/orders/recover). En cas de doute sur le paiement, [contactez
  l’assistance](/orders/support) avant de payer à nouveau.
</Callout>

## Du paiement au téléchargement [#from-payment-to-your-zip]

1. **Vérifiez la confirmation du paiement.** PyColors crée l’accès après confirmation du paiement par le serveur. Une redirection du navigateur ne suffit pas à confirmer le paiement, l’arrivée de l’e-mail ou le téléchargement.
2. **Retrouvez l’e-mail d’accès.** Il est envoyé à l’adresse utilisée lors de la commande. Un accès peut exister même si le message n’est pas arrivé. Le [reçu ou la facture](/docs/starter-pro/purchase-documents) se récupère séparément.
3. **Ouvrez le lien de cet e-mail.** Vérifiez que la page affiche le produit commandé. Une mise à niveau Fullstack payée possède son propre e-mail d’accès. L’ancien lien Web ou Mobile ouvre toujours l’achat d’origine. Chaque lien d’accès expire 24 heures après son émission. Gardez-le privé.
4. **Sélectionnez « Télécharger [nom du produit] ».** Attendez la fin du téléchargement, conservez le ZIP et décompressez-le. Lisez le `README.md` à la racine et suivez le [guide correspondant à votre archive](#match-your-archive). À ce stade, l’hébergement et les services de votre application restent à configurer.

## Vérifier l’archive reçue [#match-your-archive]

Dans le formulaire de récupération, choisissez le nom exact du produit figurant sur votre commande. Après le téléchargement, ouvrez `PYCOLORS_RELEASE.json` dans le dossier extrait. Le format actuel indique l’offre dans `productSlug` et la révision du code source dans `sourceCommit`.

| Produit sur la commande et dans le formulaire | Valeur attendue de `productSlug` | Point de départ                                                                |
| --------------------------------------------- | -------------------------------- | ------------------------------------------------------------------------------ |
| PyColors Starter Pro                          | `starter-pro`                    | [Installation Web](/docs/starter-pro/getting-started) depuis la racine         |
| PyColors Starter Pro Mobile                   | `starter-pro-mobile`             | [Installation Mobile](/docs/starter-pro/mobile) avec `backend/` et `mobile/`   |
| PyColors Starter Pro Fullstack                | `starter-pro-fullstack`          | [Installation Fullstack](/docs/starter-pro/fullstack) avec `web/` et `mobile/` |

Certaines anciennes archives Web indiquent la version et la révision du code sans champ d’offre. Suivez le README livré avec cette version. Si le produit ou les fichiers diffèrent de votre commande, conservez le ZIP et [contactez l’assistance](/orders/support) avant l’installation. L’[historique des versions](/product-releases) permet de situer les mises à jour. Les fichiers reçus identifient votre exemplaire.

Pour les droits d’utilisation, consultez le fichier `LICENSE` fourni et les [conditions de licence](/license). Avant de mettre votre application Web ou Fullstack en production, validez vos services avec la [checklist de production](/docs/starter-pro/production-checklist). Pour une distribution native, suivez les vérifications sur appareil et les étapes de signature du guide Mobile ou Fullstack.

## En cas de problème [#when-a-delivery-step-fails]

### Le paiement est en attente ou incertain [#payment-is-pending-or-uncertain]

La [page de paiement interrompu](/checkout/cancel) ne vérifie pas le statut de votre paiement. En cas de doute, [contactez l’assistance](/orders/support) avec l’adresse utilisée, le nom du produit et la date approximative. Une demande de récupération ne termine pas un paiement en attente.

### L’e-mail d’accès n’arrive pas [#no-claim-email-arrives]

Vérifiez les courriers indésirables. Dans le [formulaire de récupération](/orders/recover), saisissez l’adresse utilisée lors du paiement, choisissez le produit commandé et sélectionnez **Renvoyer le lien d'accès**. Le formulaire affiche une confirmation générique. Les demandes répétées peuvent être temporairement limitées. Si l’e-mail manque toujours, suivez le [guide de récupération](/docs/starter-pro/purchase-recovery).

### La page indique que le lien est invalide [#the-page-says-invalid-access-link]

Ouvrez le lien complet depuis l’e-mail. Si vous ne le retrouvez plus, demandez-en un nouveau. Évitez de reconstituer l’adresse à la main.

### La page indique que le lien est indisponible [#the-page-says-access-link-unavailable]

Le lien a pu expirer ou le service être temporairement indisponible. Réessayez un peu plus tard ou demandez un nouveau lien. Si le problème persiste, contactez l’assistance.

### Le téléchargement échoue après la vérification d’accès [#the-download-fails-after-access-is-ready]

Vérifiez votre connexion et relancez le téléchargement. Si le lien a expiré, demandez-en un nouveau. Si le ZIP reste indisponible ou illisible, transmettez le nom du produit et le message d’erreur à l’assistance. Vous n’avez pas besoin de racheter le produit pour réessayer.

### Le lien ouvre un autre produit ou vous avez perdu l’accès à votre messagerie [#the-link-is-for-another-product-or-the-checkout-email-is-inaccessible]

Comparez le produit sélectionné avec le [tableau des offres](#match-your-archive). Seul l’accès actif du produit sélectionné peut être récupéré. Si le nouveau message ouvre toujours un autre produit ou si la boîte de réception est inaccessible, contactez l’assistance. Le formulaire ne peut pas changer l’adresse de la commande.

## Contacter l’assistance [#ask-for-purchase-support-safely]

Ouvrez l’[assistance achat](/orders/support). Indiquez l’adresse utilisée lors du paiement, le nom exact du produit, la date approximative, la référence de commande si vous l’avez et l’étape qui a échoué. Si votre application de messagerie ne s’ouvre pas, la page fournit l’adresse à copier.

Gardez les mots de passe, informations de carte, clés API et liens privés hors de votre message et de vos captures d’écran. Aucun délai de réponse ou de résolution n’est garanti. Pour une rétractation ou une demande de remboursement, consultez les [conditions et coordonnées prévues](/orders/support#refunds).
