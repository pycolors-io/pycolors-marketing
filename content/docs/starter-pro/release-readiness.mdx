<Callout title="What automated coverage establishes">
  The required CI gate waits for source validation and the selected browser
  suite. A skipped or missing selected check cannot make the gate pass. Provider
  interception keeps these tests independent of live email and payments. It does
  not establish live delivery or a successful real transaction. Your launch
  acceptance includes your own email and Stripe configuration.
</Callout>

## How the packaging gate works

<Steps>
  <Step>
    ### Extract and install

    Export the standalone source and extract it outside the monorepo. Install
    the supplied lockfile without relying on workspace dependencies.

  </Step>
  <Step>
    ### Migrate and compile

    Apply the committed migrations to an empty disposable database, run unit
    checks and compile the extracted production application.

  </Step>
  <Step>
    ### Complete a first-user journey

    Exercise registration, verification, sign-in, workspace creation, invitation
    and project work. Reload to verify persistence, then remove the temporary
    database and retain the local validation evidence.

  </Step>
</Steps>

## Know what you receive

The ZIP includes a standalone manifest, lockfile, reviewed dependency patches,
Prisma migrations and buyer guides. `PYCOLORS_RELEASE.json` records its version,
source commit and source-file hashes. Save it with the original delivery before
customizing the application. Intentional edits naturally change file hashes.

The included `docs/quickstart.md`, `docs/customization.md`, `docs/upgrading.md`,
`docs/operations.md` and `docs/support.md` remain available with your source.

<Callout title="Billing ownership and limits">
  Application billing belongs to the **user account**. Workspace creation and
  resource quotas are configurable and **uncapped by default**.
  Organization-owned billing requires its own ownership and migration design.
  The source licence, your application's subscription and an agreed
  implementation service are distinct purchases.
</Callout>
