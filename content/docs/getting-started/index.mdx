## Before you begin

- **PyColors UI:** have a React app with Tailwind CSS v4 and a global stylesheet.
  The [installation guide](/docs/ui/installation#prerequisites) covers the
  package requirements and CSS setup.
- **Starter Free:** have Git, Node.js, and pnpm. Clone the public starter using
  its [installation guide](/docs/starter/installation). Its auth, billing, and
  data flows are mocked; you do not need production service credentials to
  explore them.
- **NA-AI Landing:** download and unzip your purchased template, then follow
  the [setup guide](/docs/templates/na-ai-landing/setup). The base template is
  frontend-only.
- **Starter Pro:** download and unzip your purchased starter, then follow its
  [local setup sequence](/docs/starter-pro/getting-started#setup-flow). This path
  includes environment and database configuration.

For a starter or template, use the Node.js and package-manager versions declared
by the project you downloaded. Run its commands from that project's root.
For UI, run the install command inside the app that will consume the package.

## Verify your first result

Complete the check for your chosen path before changing the project structure.

### PyColors UI

Follow [Installation](/docs/ui/installation) to install the packages, load token
CSS, register the package with Tailwind, and render the example card.

Your first result is a styled card and link in your own app. Confirm light and
dark styles, visible keyboard focus, and a passing app build. Then use
[usage patterns](/docs/ui/usage-patterns) to compose your next screen, or
[migration guidance](/docs/ui/migration-guidance) when replacing existing UI.

### Starter Free

Follow [Installation](/docs/starter/installation), start the local server, and
open `/dashboard` and `/projects`. Try a project action and navigate to settings.

Your first result is a navigable SaaS demo with mock data. Continue with
[the first-run walkthrough](/docs/starter/getting-started#first-run-path), then
adapt one product surface. These screens do not establish real accounts,
payments, or persistent backend data.

### NA-AI Landing

Follow [Setup](/docs/templates/na-ai-landing/setup) to run the downloaded template.
Confirm the homepage renders, check its light and dark modes, and run the
documented production build.

Your first result is a local landing page that builds successfully. Continue
with [Customization](/docs/templates/na-ai-landing/customization) to update your
branding and content.

### Starter Pro

Follow [Getting started](/docs/starter-pro/getting-started) in order: unpack,
install, configure the local environment, set up the database, and start the app.
Use that guide's foundation checks for sign-in and protected routes before
customizing the product.

Your first result is a working local foundation. Running locally is one step
toward launch; follow the product's separate configuration and validation guides
before relying on authentication, billing, or delivery in production.

## If setup does not work

- **Components render without styling:** check the
  [global CSS and package scan path](/docs/ui/installation#add-design-tokens).
  Installing the JavaScript package alone does not generate its Tailwind styles.
- **Dependency or runtime errors:** compare your local Node.js and pnpm versions
  with the downloaded project's manifest before reinstalling. Use the
  troubleshooting section of your product's setup guide.
- **Starter Free does not save real users or payments:** this is its
  [frontend-only boundary](/docs/starter/getting-started#know-what-is-intentionally-mocked).
  Read the [upgrade guide](/docs/starter/upgrade) when backend wiring becomes
  your next step.

Once your first result works, follow the next guide for that product. You can
return here when a different PyColors product matches the next thing you need
to build.
