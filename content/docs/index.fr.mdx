      <Tab value="Installer l’UI">

```bash title="Terminal"
pnpm add @pycolors/ui @pycolors/tokens
```

Dans une application React avec Tailwind CSS v4, [connectez ensuite les styles](/docs/ui/installation).

      </Tab>
      <Tab value="Lancer Starter Free">

```bash title="Terminal"
git clone https://github.com/pycolors-io/pycolors-starter-free.git
cd pycolors-starter-free
pnpm install
pnpm dev
```

Explorez le frontend avec ses données de démonstration. [Suivre l’installation](/docs/starter/installation).

      </Tab>
      <Tab value="Configurer Pro">

```bash title="Terminal"
cp .env.example .env
pnpm install --frozen-lockfile
```

Après avoir téléchargé et décompressé votre achat, exécutez ces commandes dans son dossier. [Continuer la configuration](/docs/starter-pro/getting-started).
